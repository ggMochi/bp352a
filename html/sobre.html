O que é este projeto?

Este projeto é uma plataforma de visualização de dados epidemiológicos sobre Doenças Tropicais Negligenciadas (DTNs) no Brasil. A ferramenta permite consultar, explorar e analisar dados oficiais da Organização Mundial da Saúde (OMS), facilitando o acesso a informações de saúde pública de forma clara e interativa.

As DTNs são um grupo de doenças infecciosas que afetam predominantemente populações em situação de vulnerabilidade social e econômica. Apesar de causarem grande sofrimento e impacto socioeconômico, essas doenças recebem historicamente menos atenção e investimento em pesquisa e tratamento.

Por que monitorar DTNs?

📊

Dados para Decisões

O monitoramento contínuo permite que gestores de saúde identifiquem tendências e tomem decisões baseadas em evidências.

🌍

Impacto Global

As DTNs afetam mais de 1 bilhão de pessoas no mundo. O Brasil é um dos países com maior carga dessas doenças nas Américas.

⚠️

Populações Vulneráveis

Comunidades com acesso limitado a saneamento básico e serviços de saúde são as mais afetadas pelas DTNs.

🎯

Metas de Eliminação

A OMS estabeleceu metas ambiciosas para controlar ou eliminar várias DTNs até 2030, e o acompanhamento dos dados é essencial.

Fonte dos Dados

Global Health Observatory (GHO) - OMS

Todos os dados apresentados nesta plataforma são obtidos diretamente da API do Global Health Observatory, o repositório oficial de estatísticas de saúde da Organização Mundial da Saúde.

Os dados são coletados e validados pela OMS em conjunto com os ministérios da saúde de cada país, garantindo a confiabilidade e a padronização das informações.

Como usar a plataforma

1

Selecione uma Doença

No Painel Principal, use o menu suspenso para escolher a doença ou indicador que deseja consultar.

2

Analise os Dados

Visualize os dados mais recentes, a evolução temporal em gráficos e tabelas detalhadas por ano.

3

Explore Indicadores

Use o Explorador de Indicadores para buscar outros indicadores de saúde disponíveis na base da OMS.
